Editar Clique para configurar

BTC 40% ETH 15% NEAR 10% LINK 5% LDO 5% MKR 5% ADA 5% USD 15%

💡
O que e a Alocacao Ideal?E o percentual alvo de cada ativo (ex: BTC 40%, ETH 15%, USD 15%). A soma deve ser exatamente 100%. A margem de erro (5%) define quando um ativo esta "fora da faixa" — se BTC esta em 33% com alvo de 40%, esta fora.
💡
Correspondencia com a planilhaNa planilha, coluna D "% Ideal" era preenchida manualmente. Aqui voce configura uma vez e o sistema calcula automaticamente para todos os clientes.

Planilha vs TradeLink

Como cada funcionalidade da planilha foi digitalizada:

Planilha TradeLink
50 abas (1 por cliente) ✓ Painel unico com todos os clientes
% Ideal preenchida manualmente ✓ Alocacao ideal configurada 1x na carteira
SUMPRODUCT para saldo ✓ Calculo automatico + historico
Comprar/Vender flag manual ✓ Analise automatica com margem de erro
Copiar/colar recomendacao ✓ Gera recomendacoes em lote + notifica clientes
Sem notificacao ✓ E-mail + Push + Telegram automaticos
GOOGLEFINANCE para precos ✓ Cotacoes em tempo real com API
Abrir cada aba para ver saude ✓ Dashboard com health dots + painel consolidado
